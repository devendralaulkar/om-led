# om-led

A small PCB board which can be used to develop basic soldering skills
Create the symbol "Om" in Devnagri using at a minimum of 20 LED's and maximum 30 LED's
The symbol should flash at the rate of 1Hz.

Part: Standard LED's, transistors, timing resistors, capacitors
Power: Using 2-3 AA batteries
Constraints: One or two layers, under 100 by 100 mm, all parts on top side, basic parts.
